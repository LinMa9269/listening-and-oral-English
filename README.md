# Listen Lab 2.2 · 可以长期保存的原声学习库

## 开始使用

1. 把压缩包**完整解压到一个固定文件夹**，不要在压缩软件里直接运行。
2. 电脑需已安装 Python 3.11 或更高版本（64 位，建议 3.11–3.13）。安装时勾选 Add Python to PATH。
3. 双击 **start.bat**。首次会自动创建本地运行环境并安装依赖，需要联网，可能耗时几分钟。
4. 浏览器会打开 **http://127.0.0.1:8765**。请保持启动窗口运行。
5. 点击「添加本地视频」：先保存原文件副本，再自动排队识别声音中的字幕，无需手动点击转写。
6. 输入生词或短语并点击「存入」。新增生词保留之前的记录；点击任意已存单词，回到它对应的原声片段。

以后仍然双击 **start.bat**，即可继续上次的学习。新版的自动识别与长期存档需要本地服务；单独双击 HTML 只会显示启动提示。

## 会保存什么

每次上传创建一个独立视频记录，包含：

- 视频文件副本（上传成功后原文件移动或删除也不会影响存档）。
- 自动识别或手动导入的字幕与时间轴。
- 累积的生词和短语，包括暂时找不到匹配字幕的词。
- 播放位置、速度、字幕偏移和上次选择的生词。

新增视频不会覆盖已有视频，左侧「我的视频」可随时切换。重复输入相同单词（忽略大小写）会打开原记录。

字幕文本每次进入练习都默认隐藏，点击「显示文本」才揭晓。音频来自视频原声，支持重复播放和变速；不生成独立 MP3，也不使用 TTS 替代原声。

## 抖音链接与视频直链

展开「从抖音链接 / 视频直链导入」，粘贴完整抖音分享内容或链接。程序提取链接，在后台尝试下载，成功后自动识别并长期保存视频副本。

**抖音是尽力支持，不能保证所有链接都能导入。** 平台可能要求登录、新 Cookie、验证码，或改变接口。当前使用 yt-dlp 的公开解析能力，不读取浏览器登录信息，不绕过平台限制。失败会保留任务记录和原因，可点击「重试链接导入」，或在抖音保存可下载的视频后上传本地文件。

还支持以 `.mp4`、`.webm` 等扩展名结尾的公网媒体直链。不支持直播、私密或付费视频、DRM、播放列表和一般网页链接。仅下载你有权使用的视频。

识别的是**视频声音**，不是 OCR 提取画面上印出的字幕。中英文由模型自动判断，中文视频不会自动翻译成英文。若要练英语，建议选含清晰英语人声的视频。

## 模型、网络与隐私

默认使用多语言 Whisper `base` 模型在 CPU 上识别，无需 API 密钥。第一次需要联网下载模型（约 150 MB），下载后缓存于程序旁的 `models` 文件夹。录音或视频不会上传到语音识别云服务。链接导入会访问视频来源；首次依赖安装和模型下载会访问相应公共服务。

长视频可能识别较慢，建议首次使用 1–3 分钟视频，单文件限制 500 MB。关闭网页不影响正在运行的后台任务；关闭启动窗口会中断识别，下次可重试。识别错误不会删除视频或生词。

如果模型下载失败，请检查到 Hugging Face 的网络连接，之后重新识别。也可以用已有的 faster-whisper 模型目录：在启动前设置环境变量 `LISTEN_LAB_MODEL` 为该目录的完整路径。始终可以手动导入 UTF-8 的 SRT / VTT 字幕继续练习。

手动字幕会取代该视频的自动字幕；正在运行的旧转写结果不会再覆盖手动字幕。点击「重新识别字幕」会明确启动新的转写，成功后替换字幕，保留生词。

## 调整片段时长（2.2 新增）

每张原声片段卡片现在包含「起点」和「终点」调节条，也可直接输入秒数，以 0.05 秒为步长调整。上方显示起止时间及片段总时长。

1. 等待视频加载后，拖动调节条或输入秒数，延长或缩短片段。
2. 点击「听原声」试听当前范围；勾选循环后按此范围重复播放。
3. 点击「保存范围」，下次打开仍然保留。未保存的调整在切换生词、视频或刷新后不保留。
4. 点击「恢复原范围」，移除自定义范围，回到字幕时间加当前字幕偏移的播放方式。

自定义范围使用**视频本身的时间**，不会再叠加字幕偏移。起点需早于终点，至少保留 0.05 秒，不能超出已加载的视频时长。没有可播放媒体或媒体尚未加载时无法调整。

保存按「视频中的这条字幕」生效；同一字幕在多个生词下出现时共用该播放范围。它不修改字幕文字，也不改变导出的 VTT 字幕时间。重新识别或导入新字幕会重置自定义范围，避免把旧范围套到新字幕上。

## 删除与回收站（2.1 新增）

视频右侧的「删除」和生词旁的「×」会先询问，再把对应内容移入回收站。删除视频会一起隐藏其字幕、生词与播放进度，**不会删除你在电脑其他位置的原始文件**。单独删除生词不改动字幕。

点击左侧「回收站 · 保留 30 天」查看删除日期和剩余天数，可恢复或永久删除。永久删除需要再次确认；视频存档副本和关联记录会一起清理，无法从程序中撤销。

- 视频和单独删除的生词保留 30 天。整个视频进入回收站后，所有子记录按视频的删除时间统一保留。
- 恢复视频不会自动恢复此前单独删除的生词；恢复视频后再到回收站恢复那些词。若其自身保留期已经到期，下一次清理时会移除。
- 再次输入同一个已删除生词会恢复原记录，不会新增重复词条。
- 程序启动时清理到期内容，运行中每小时检查一次。程序关闭时不会运行清理任务，到期内容在下次启动时清理。
- 正在识别的视频删除后，旧结果会作废；恢复后可重新识别或重试链接。取消可能需等待当前识别步骤或网络请求返回。
- 文件占用时显示「等待清理」，释放识别任务后或下一次定时检查时重试。已开始永久清理的记录不能再恢复；不会将等待清理误报为删除完成。

## 从 2.0 / 2.1 升级

先关闭旧版启动窗口。把新版完整解压到新文件夹，将旧版的完整 **data** 和 **models** 文件夹复制到新版程序旁，然后双击新版 **start.bat**。确认视频与生词都在后，再处理旧程序文件夹。无需重新上传；不要同时运行新旧版操作同一个 data 目录，也不要用旧版程序打开已被新版修改的存档。

## 备份和换电脑

关闭程序后，复制完整 **data** 文件夹：

```
data/
  records/  每个视频的字幕、单词和播放设置
  media/    已保存的视频文件
```

回收站内容也保存在 `data` 中，随整个文件夹一起备份。恢复旧备份不会重置删除日期；已到期内容仍会在启动时清理。

恢复时，把完整 `data` 放到新版程序旁，再启动。不要只备份 records，否则没有原声视频。更新程序时保留 `data` 和 `models`。存档保存在磁盘，不依赖浏览器缓存；清理浏览器缓存不会清除学习库，但可能重置默认打开的视频。

关闭页面时会尝试保存最近位置，并在播放中约每 5 秒保存；异常断电最多可能丢失最近几秒的播放进度。

## 故障排查

- 启动失败：先确认安装了 Python；也可在本目录执行 `python launcher.py`。
- 安装依赖失败：学习库和手动字幕导入仍可使用；网络恢复后重新运行 start.bat。
- 端口占用：先关闭上次启动窗口，再运行新版本。也可设置 `LISTEN_LAB_PORT` 为其他空闲端口。
- 视频打不开：可能是浏览器不支持该编码，建议 MP4（H.264 / AAC）。存档与字幕不会因此消失。
- 找不到生词：按完整单词匹配，不自动扩展词形，例如 run 不匹配 running；检查识别文本是否有误。
- 时间不对：调整字幕偏移，正数让片段稍后播放。字幕按识别片段切分，可能不是完整语法句。
- 数据目录无写入权限或磁盘满：改放到可写的个人文件夹，或设置 `LISTEN_LAB_DATA_DIR`。不要同时运行两个程序修改同一存档目录。

## 技术与验证

本地转写：[faster-whisper](https://github.com/SYSTRAN/faster-whisper)。链接解析：[yt-dlp](https://github.com/yt-dlp/yt-dlp)。抖音限制参考：[项目公开问题记录](https://github.com/yt-dlp/yt-dlp/issues/16803)。

依赖固定了与 faster-whisper 兼容的 PyAV 16.1.0，避免较新解码库的接口变化。该项目使用 PyAV 解码，无需单独安装系统 FFmpeg。

验证结果见随包的 `验证说明.md`。自动测试通过不等于任意平台链接都能下载，也不代表字幕完全无误。
